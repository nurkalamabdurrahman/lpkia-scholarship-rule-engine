# LPKIA Scholarship Rule Engine

A web-based scholarship eligibility evaluation system powered by a Decision Tree algorithm and IF–THEN production rules.

## Features

- **Eligibility Prediction** — Evaluate scholarship applicants based on predefined criteria.
- **Batch Evaluation** — Process multiple applicants using CSV files.
- **Decision Tree Visualization** — Display the decision-making process.
- **Rule-Based Explanation** — Show IF–THEN rules behind each prediction.
- **CSV Export** — Download evaluation results.

## Evaluation Criteria

- GPA (IPK)
- Parental Income
- Number of Family Dependents
- Organizational Involvement

## Tech Stack

- Python
- Scikit-learn
- Pandas
- HTML5, CSS3, JavaScript
- GitHub Pages
